## Reporting a Vulnerability

The Kyzen team takes security seriously. If you discover a security vulnerability in Kyzen, please **do not open a public issue**.

Instead, please report security issues privately via:
1. **GitHub Security Advisory:** Create a draft advisory under the repository's `Security` tab.
2. **Email:** Send details directly to `security@kyzen.dev` (or the project maintainer).

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested remediations or mitigations.

### Response Timeline
- **Initial Acknowledgement:** Within 48 hours.
- **Triage & Status Update:** Within 5 business days.
- **Fix & Disclosure:** Coordinated release and CVE assignment as appropriate.
