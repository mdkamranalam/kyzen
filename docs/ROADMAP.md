# Kyzen Roadmap

This document outlines the milestones and roadmap for Kyzen toward its public open-source v1.0 release.

---

## 🎯 Milestone 1: Multi-Tenant Core & Authentication (Weeks 1–3)
- [ ] Schema modeling: Organizations, Memberships, Projects, Tasks
- [ ] Full OAuth (GitHub/Google) & Developer Credentials integration
- [ ] Multi-tenant workspace switcher & session context
- [ ] RBAC authorization helper functions

---

## 🎯 Milestone 2: Projects & Interactive Kanban Board (Weeks 4–7)
- [ ] Project CRUD & project dashboard views
- [ ] Task state management & drag-and-drop Kanban board
- [ ] Task detail drawer (Markdown descriptions, assignees, labels, due dates)
- [ ] Optimistic UI updates with TanStack Query & Zustand

---

## 🎯 Milestone 3: AI Assistant & Productivity Integrations (Weeks 8–10)
- [ ] AI Service layer (streaming responses, structured outputs)
- [ ] AI Task breakdown generator
- [ ] AI Code Review assistant component
- [ ] Rate limiting & token usage management

---

## 🎯 Milestone 4: Notifications & Activity Audit Stream (Weeks 11–13)
- [ ] Activity logger for task and project mutations
- [ ] In-app notification center & unread count badge
- [ ] Member invitation via email tokens

---

## 🎯 Milestone 5: Testing, Hardening & Open-Source Release (Weeks 14–17)
- [ ] Automated testing suite (Vitest for services, Playwright for critical user flows)
- [ ] Docker Compose self-hosting setup
- [ ] GitHub Actions CI/CD workflows
- [ ] Open-source launch & community onboarding documentation
